# benhollar.com

This is my personal website, built using [Astro](https://astro.build/) and custom-styled (though inspired heavily by
the [Minimal Mistakes](https://mmistakes.github.io/minimal-mistakes/)) theme the website was previously built with.

## Running Locally

1. Follow the steps listed on Astro's documentation to [install Astro](https://docs.astro.build/en/install-and-setup/).
2. Clone the repository.
3. Launch the [Astro dev server](https://docs.astro.build/en/develop-and-build/#start-the-astro-dev-server).
